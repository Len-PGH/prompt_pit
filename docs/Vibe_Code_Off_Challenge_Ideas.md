# **Vibe Code-Off Challenge Ideas**

## *Prompts ranked from quick-fire builds to championship-level chaos, followed by a large bank of surprise modifiers.*

**QUARTERFINALS | APPROX. 5-7 MINUTES**

# **Level 1: Quick-Fire Builds**

*Ordered from easiest to hardest. Each challenge should produce one obvious, demonstrable interaction.*

**1\. Meeting Cost Calculator**

**Prompt:** Build a calculator that accepts attendee count, meeting length, and average hourly compensation.

**Complete when:** It shows total cost, cost per minute, and a ridiculous equivalent such as pizzas, goats, or months of streaming subscriptions.

**2\. Excuse Generator**

**Prompt:** Accept a situation and generate three excuses labeled Believable, Risky, and Career-Limiting.

**Complete when:** The host enters “I missed the morning meeting” and receives three labeled, copyable excuses.

**3\. Corporate Translator**

**Prompt:** Translate blunt language into corporate language and corporate language back into blunt language.

**Complete when:** “We have no idea why it broke” can be converted both directions without losing the basic meaning.

**4\. Executive Decision Machine**

**Prompt:** Accept a decision and up to three choices, pick one, and explain why.

**Complete when:** A “Regret This Decision” button immediately picks again and gives a new justification.

**5\. Bad Idea Detector**

**Prompt:** Accept an idea, score it from 0 to 100, and explain the score.

**Complete when:** It visibly reacts differently to a good idea and “Uber, but for emotional-support raccoons.”

**6\. Tiny Support Desk**

**Prompt:** Accept a complaint, assign priority and category, and draft a first response.

**Complete when:** “Production is down” is treated differently from “the logo feels judgmental.”

**7\. Reverse To-Do List**

**Prompt:** Let users enter things they already completed and reward them for retroactive productivity.

**Complete when:** Items can be added and removed, points increase, and the praise changes each time.

**8\. Startup Name Generator**

**Prompt:** Accept a product description and generate five startup names with taglines.

**Complete when:** At least one name sounds fundable, one sounds legally dangerous, and one has an unnecessary missing vowel.

**9\. CEO Mood Ring**

**Prompt:** Accept a short company update and classify the CEO’s likely mood.

**Complete when:** The app returns a mood, confidence score, and suggested safe response such as “Great point” or “I’ll circle back.”

**10\. Passive-Aggressive Email Decoder**

**Prompt:** Translate a polite workplace sentence into what it probably means.

**Complete when:** “Just following up” and “Per my last email” produce different decoded meanings and danger levels.

**11\. Petty Complaint Composer**

**Prompt:** Accept a minor inconvenience and turn it into an absurdly formal complaint.

**Complete when:** The output contains a dramatic subject line, the grievance, and an unreasonable demand for restitution.

**12\. Fortune Cookie Legal Department**

**Prompt:** Generate fortune-cookie advice with a completely unnecessary legal disclaimer.

**Complete when:** A button creates a new fortune and the disclaimer is longer than the wisdom.

**13\. Password Judgment Engine**

**Prompt:** Evaluate a password without echoing it elsewhere on the page.

**Complete when:** It shows strength, explains weaknesses, and generates a stronger suggestion.

**14\. Emergency Landing Page**

**Prompt:** Build a responsive launch page for a fictional product announced by the host.

**Complete when:** It has a headline, three benefits, a call to action, and at least one working interaction or state change.

**SEMIFINALS | APPROX. 8-10 MINUTES**

# **Level 2: Multi-Step Workflows**

*These require multiple states, prioritization, a small workflow, or a more substantial generated result.*

**1\. API Status Dashboard**

**Prompt:** Create three fictional services with operational, degraded, and down states.

**Complete when:** The user can change service state, see incident history, and get an overall system status.

**2\. Inbox Triage Simulator**

**Prompt:** Show at least six messages and sort them into Urgent, Reply, Delegate, or Ignore.

**Complete when:** The user can reclassify messages, see category counts, and generate a reply for one selected message.

**3\. Incident Commander**

**Prompt:** Accept an incident, assign severity, generate a checklist, and produce a customer update.

**Complete when:** At least three actions can be checked off and the customer update reflects the incident.

**4\. Travel Disaster Assistant**

**Prompt:** Create a recovery plan from a destination, disruption, time constraint, and user priority.

**Complete when:** It produces at least three ordered actions and changes the plan when the priority changes.

**5\. Product Review Investigator**

**Prompt:** Analyze a group of reviews for score, praise, complaints, and suspicious entries.

**Complete when:** It identifies recurring themes, flags one weak or suspicious review, and recommends buy or skip.

**6\. Smart Queue**

**Prompt:** Route tasks to workers based on urgency and required skills.

**Complete when:** At least three workers and five tasks are shown, and a newly added task is assigned appropriately.

**7\. Conference Networking Assistant**

**Prompt:** Match a person’s role, interests, and objective to people in a supplied attendee list.

**Complete when:** It recommends three people, explains each match, and creates an opening line for one selection.

**8\. Escape Room**

**Prompt:** Build a small interactive puzzle with at least two sequential clues.

**Complete when:** The user cannot skip directly to the end, can win, and can reset the game.

**9\. Office Lunch Peace Treaty**

**Prompt:** Plan lunch for a group with conflicting dietary restrictions, budgets, and emotional attachments to restaurants.

**Complete when:** It finds a workable plan, identifies the biggest conflict, and explains who will still complain.

**10\. Code Therapist**

**Prompt:** Accept an error message or broken snippet and respond like a therapist who is also technically competent.

**Complete when:** It diagnoses the likely issue, suggests concrete fixes, and asks one uncomfortably insightful follow-up question.

**11\. Employee Awards Generator**

**Prompt:** Accept a list of names and workplace facts and create personalized fake awards.

**Complete when:** Each person gets a distinct award, citation, and acceptance-speech prompt; duplicates are avoided.

**12\. Conspiracy Corkboard**

**Prompt:** Accept several unrelated facts and build a visual or textual theory connecting them.

**Complete when:** The theory shows at least four connections, highlights the weakest leap, and includes a “This Is Obviously True” confidence meter.

**13\. Apology Escalation Engine**

**Prompt:** Turn a small mistake into three increasingly serious apologies.

**Complete when:** The outputs range from casual acknowledgment to full televised resignation, while retaining the original facts.

**14\. Choose Your Own Disaster**

**Prompt:** Create an interactive story with at least three decisions and multiple endings.

**Complete when:** Earlier choices affect later options, there are at least two endings, and the final screen summarizes the path.

**CHAMPIONSHIP | APPROX. 11-15 MINUTES**

# **Level 3: End-to-End Mini Products**

*These demand a complete experience with multiple behaviors and a memorable final demonstration.*

**1\. Human Versus Bureaucracy**

**Prompt:** Guide a user through a fictional bureaucratic process such as obtaining a dragon permit or registering a time machine.

**Complete when:** It collects information, validates fields, shows progress, detects missing data, and produces a completed application or action plan.

**2\. The Impossible Concierge**

**Prompt:** Handle a complicated request with multiple constraints and at least one conflict.

**Complete when:** The app extracts constraints, identifies the conflict, asks or simulates a clarification, and revises the plan.

**3\. Real-Time Operations Center**

**Prompt:** Display simulated incoming events, classify severity, update metrics, and let an operator resolve events.

**Complete when:** Events visibly arrive or change over time and a final incident summary can be generated.

**4\. Rescue This Business**

**Prompt:** Diagnose a fictional struggling business from complaints, basic metrics, and one operational constraint.

**Complete when:** It identifies the main problem, prioritizes three actions, creates a customer-facing artifact, and shows a simple before-and-after projection.

**5\. Multi-Agent War Room**

**Prompt:** Have at least three roles evaluate the same problem from different perspectives.

**Complete when:** Each role recommends an action, disagreements are identified, a combined decision is produced, and changing one fact changes the outcome.

**6\. Fix the Broken Product**

**Prompt:** Repair a deliberately incomplete starter app or API and add one feature announced by the host.

**Complete when:** The primary workflow works, errors are handled visibly, and both a success case and failure case are demonstrated.

**7\. Build the Company**

**Prompt:** Create a complete mini-product for a ridiculous startup announced at the start of the round.

**Complete when:** It includes onboarding or a landing screen, one core workflow, meaningful output, session persistence, and a polished success state.

**8\. Shark Tank From Hell**

**Prompt:** Build an app that evaluates a terrible startup pitch from market, technical, financial, and moral perspectives.

**Complete when:** It produces separate verdicts, exposes contradictions, calculates a nonsense valuation, and lets the user negotiate with hostile investors.

**9\. Crisis PR Spin Room**

**Prompt:** Respond to a fictional corporate crisis with internal and external communications.

**Complete when:** It creates an internal briefing, public statement, hostile press Q\&A, and updates the messaging when a new damaging fact arrives.

**10\. Disaster Wedding Planner**

**Prompt:** Plan a wedding under impossible constraints announced by the host.

**Complete when:** It creates a schedule, seating or guest logic, budget allocation, contingency plan, and visibly handles one surprise disaster.

**11\. Time-Travel Support Desk**

**Prompt:** Support customers whose problems involve time loops, paradoxes, and purchases made before the company existed.

**Complete when:** It tracks the customer’s timeline, identifies a paradox, proposes a resolution, and prevents at least one action that would erase the ticket.

**12\. Build for the Audience**

**Prompt:** Let the audience choose a user, problem, visual personality, and one bizarre mandatory feature.

**Complete when:** The final app clearly serves the chosen user, solves the problem, incorporates the theme, implements the bizarre feature, and completes one end-to-end workflow.

**REVEAL MID-ROUND OR AT THE START**

# **Surprise Modifier Bank**

*Choose one modifier for a semifinal or championship. Practical modifiers test adaptability; chaos modifiers test whether contestants can keep a straight face.*

**Practical Modifiers**

| Modifier | What changes |
| :---- | :---- |
| **Dark Mode** | Add a functional dark mode, not merely a button that changes one background. |
| **Mobile Panic** | The primary workflow must work at a narrow phone-sized width. |
| **Undo That** | Add an undo action for the most important destructive operation. |
| **Second Persona** | Support a second user type with visibly different needs or output. |
| **Export It** | Add copy, download, print, or share behavior for the final result. |
| **Empty Means Empty** | Handle an empty submission with a useful response rather than an explosion. |
| **Garbage In** | Handle deliberately invalid, contradictory, or malformed input. |
| **Keyboard Only** | Make the core workflow usable without a mouse. |
| **Refresh Survival** | Preserve meaningful state after a page refresh. |
| **Clock Is Ticking** | Add a timer, countdown, deadline, or elapsed-time display that affects behavior. |
| **Voice of Reason** | Add one useful voice input or voice output interaction. |
| **Something Happened** | Add a simulated real-time event that changes the interface without a manual refresh. |
| **Failure Is a Feature** | Demonstrate a failure state and a clear recovery path. |
| **Explain Yourself** | Add a concise explanation of why the app produced its result. |

**Chaos Modifiers**

| Modifier | What changes |
| :---- | :---- |
| **Maximum Chaos Mode** | Add a toggle that makes the experience dramatically more unhinged while remaining usable. |
| **Five-Year-Old Mode** | Explain the final result as if the user is five years old. |
| **Board Meeting Mode** | Translate every output into language that says almost nothing while sounding expensive. |
| **Legal Has Entered the Chat** | Attach an absurd disclaimer to every important result. |
| **Passive-Aggressive Mode** | All helper text must sound polite while clearly expressing disappointment. |
| **Clippy’s Revenge** | Add an intrusive assistant that gives advice nobody requested. |
| **Villain Mode** | Present the same workflow from the perspective of an unnecessarily theatrical supervillain. |
| **Mom Is Watching** | Sanitize the app so every risky or rude output becomes embarrassingly wholesome. |
| **Florida Mode** | Introduce one bizarre but technically possible complication involving wildlife, weather, or local government. |
| **Late-Stage Startup Mode** | Add a metric that is rapidly increasing but has no obvious relationship to revenue. |
| **Enterprise Edition** | Add one pointless approval step, one role nobody understands, and one screen labeled Governance. |
| **Web3 Emergency** | Add a wallet-shaped visual element or blockchain reference without improving the product in any way. |
| **AI Everywhere** | Rename at least three ordinary features as AI features and include one glowing gradient. |
| **The Intern Shipped It** | Introduce one obvious mistake, then add a visible control that repairs it. |
| **Haunted SaaS** | The app must behave as though a previous user is still trapped inside it. |
| **Medieval Mode** | Rewrite all labels and outputs as proclamations from a royal court. |
| **Reality TV Mode** | Add confessionals, alliances, betrayal, or an elimination screen to the workflow. |
| **Unnecessary Mascot** | Add a named mascot that reacts to success, failure, and indecision. |
| **The Button Is Judging You** | The primary action button changes its label based on how long the user hesitates. |
| **Everything Is Fine** | When something fails, the interface must insist everything is fine while still showing the real recovery action. |

**Hostile Host Modifiers**

| Modifier | What changes |
| :---- | :---- |
| **Breaking News** | The host reveals one new fact that invalidates part of the current solution. |
| **Budget Cut** | Remove or simplify one feature while keeping the core completion criteria intact. |
| **Executive Request** | Add a last-minute feature that sounds trivial but affects multiple screens. |
| **Customer Escalation** | A new user appears with a conflicting requirement that must be acknowledged. |
| **Compliance Says No** | One current behavior becomes prohibited; provide a compliant alternative. |
| **The API Is Down** | Replace one external dependency with local, mocked, or fallback behavior. |
| **Brand Refresh** | The host announces a new tone or visual theme that must appear in the final demo. |
| **No More Typing** | The final step must be completed using buttons, selection, or another non-text interaction. |
| **One-Handed User** | Adapt the core workflow so it can be completed with minimal precision or interaction. |
| **Demo Gods Demand Tribute** | Add a single dramatic success moment suitable for the audience and announcer. |
